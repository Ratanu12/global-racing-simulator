## Run locally
1. Install Node.js.
2. Copy `.env.example` to `.env`.
3. Put your Razorpay **test** key ID and secret in `.env`.
4. Run `npm install`
5. Run `npm start`
6. Open http://localhost:3000

## Going live
Use your own verified Razorpay merchant account, switch to live credentials, deploy the Node server over HTTPS, and configure your domain/webhook as required by the gateway.
